# ericcurtin/scoop-bucket

Scoop bucket for [vmmbox](https://github.com/ericcurtin/vmmbox): accelerated
Linux VMs on QEMU that mirror your user.

```powershell
scoop bucket add vmmbox https://github.com/ericcurtin/scoop-bucket
scoop install vmmbox
```

This installs QEMU too. Supported: Windows x64.

`bucket/vmmbox.json` is generated by `packaging/render.sh` in the main repo and
pushed here on every release. Edits made here are overwritten; change
`packaging/scoop/bucket/vmmbox.json.in` upstream instead.
