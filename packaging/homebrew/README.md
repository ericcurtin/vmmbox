# ericcurtin/homebrew-tap

Homebrew tap for [vmmbox](https://github.com/ericcurtin/vmmbox): accelerated
Linux VMs on QEMU that mirror your user and share your home.

```sh
brew install ericcurtin/tap/vmmbox
```

The fully-qualified name taps this repo for you and trusts just this formula
(Homebrew does not load formulae from third-party taps otherwise).

On macOS, add GUI app support (windows on your desktop) with:

```sh
brew install J-x-Z/tap/cocoa-way J-x-Z/tap/waypipe-darwin
```

Supported: macOS (Apple silicon and Intel) and Linux x86_64.

`Formula/vmmbox.rb` is generated by `packaging/render.sh` in the main repo and
pushed here on every release. Edits made here are overwritten; change
`packaging/homebrew/Formula/vmmbox.rb.in` upstream instead.
